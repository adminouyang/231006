# 本地源：不参与测速，只做频道名校正后合并到输出（可关闭：--no-local）
# 格式与远程 txt 源完全一致：
#   分组名,#genre#
#   频道名,http://地址
# 一个频道多个地址用 # 分隔；也支持 m3u（首行 #EXTM3U）
#
# 示例（去掉每行开头的 # 即可生效）：
# 央视频道,#genre#
# CCTV1,http://192.168.1.10:8080/live/cctv1.m3u8
# CCTV2,http://192.168.1.10:8080/live/cctv2.m3u8
# 卫视频道,#genre#
# 湖南卫视,http://192.168.1.10:8080/live/hunan.m3u8
